Theatre of Blood Loot Simulator

A simple Old School RuneScape Theatre of Blood (ToB) loot simulator built with Vue 3 + TypeScript.
It allows you to simulate raid completions and see how RNG affects unique drops and collection log progress.

Features
Simulate Theatre of Blood raid rewards
Toggle FFA (Free-For-All) for personal drop chace
Adjustable team size
Adjustable personal MVP points
Tracks total loot obtained
Tracks collection log progress
Shows KC (kill count) for unique drops
Visual purple background when a unique is rolled

How It Works

Each roll simulates one Theatre of Blood completion.

All loot is selected using weighted drop tables to mirror the real game behaviour.

Tech Stack
Vue 3
TypeScript
Vite

Running the Project

Install dependencies:

npm install

Start the development server:

npm run dev

Then open the local URL shown in your terminal.
